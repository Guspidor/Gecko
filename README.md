# Gecko

Gecko est une application de bureau pour découvrir des films et des séries, puis reprendre facilement une lecture en cours.

## Télécharger et installer

1. Ouvrez la page [Releases](https://github.com/Guspidor/Gecko/releases).
2. Téléchargez le fichier `.msi` de la dernière version stable.
3. Ouvrez le fichier téléchargé et suivez l’assistant d’installation.

Une version marquée **Pre-release** ou **beta** est une version de test. Elle peut contenir des corrections récentes, mais aussi des défauts non encore identifiés.

## Mettre à jour

Téléchargez et installez simplement le MSI d’une version plus récente. L’installateur remplace la version précédente.

L’application peut également vous proposer une mise à jour depuis ses réglages lorsque la vérification des mises à jour est activée.

## Signaler un problème

Avant de créer un signalement, vérifiez que vous utilisez la dernière version stable. Pour nous aider à reproduire le problème, indiquez :

- la version affichée dans les réglages de Gecko ;
- votre version de Windows ;
- les étapes précises qui provoquent le problème ;
- une capture d’écran ou le message d’erreur, si possible.

Vous pouvez ouvrir un ticket sur la page [Issues](https://github.com/Guspidor/Gecko/issues).
